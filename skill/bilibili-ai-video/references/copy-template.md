# 原创文案模板（以 DeepSeek V4 Flash 实测为例，全部原创）

> 用途：给「AI 科技测评视频」搭骨架。数据必须来自官方文档/官方公告并标注来源；文案必须原创，禁止抄袭他人。

## 一、视频概述

- 选题：一句话说清「测什么 + 为什么现在测」
- 目标观众：程序员 / AI 爱好者 / 想低成本体验的开发者
- 时长建议：5~8 分钟（实测 + 教程两段式）
- 风格：B 站科技区硬核实测，开头用钩子（如「贾维斯时刻」）抓人，中间数据说话，结尾教程落地
- 核心卖点：2~3 个最有传播力的点（如百万上下文、超低价、Agent 能力）

## 二、标题候选（写 4~6 个，选 1）

1. 【钩子词】DeepSeek V4 Flash 正式版实测：喊一声"贾维斯"，它把活全干完了
2. 我把 XX 变成了贾维斯：终端、工具、写代码，全自动
3. XXX 参数只要 X 块钱/百万 token？……
4. 别再喊"AI 只是聊天工具"了，实测 Agent 能力离谱
5. 全网首发实测：1M 上下文 + 低激活参数，能不能当贾维斯？
6. 涨价前最后一次实测？上手全流程

## 三、封面文案（大字，16:10）

- 主标题：贾维斯时刻！
- 副标题：DeepSeek V4 Flash 正式版实测
- 小字卖点：1M 上下文 / 1元每百万token / Agent 大幅升级
- 画面：全息蓝光科技风，AI 正在终端里敲代码

## 四、简介模板（发布时按实际时间轴改写）

```
这期视频实测 XXX（版本号）。
相比预览版，正式版 Agent 能力大幅增强：终端操作、工具调用、全栈开发都能自己干，官方基准拿到 XX 分。
视频里我会：
00:00 钩子开场
00:52 它到底是什么：参数、上下文、价格
01:54 三个场景实测
02:58 保姆级复现教程
04:03 避坑点与结论

资料/来源：官方 API 文档、官方公告，媒体报道见画面标注。
⚠️ 注意：官方已宣布计划上调价格，想低成本体验的建议趁早。
喜欢的话点个三连，评论区告诉我你想看我用它做什么。
```

## 五、分镜脚本（时间轴 / 画面 / 旁白 / 音效）

- 【0:00-0:30】开场钩子：黑屏 → 全息蓝 UI → 终端字符滚动；旁白用「早上好，先生，我已分析完你的代码仓库……这不是电影，这是今天。」
- 【0:30-1:20】悬念 + 引出主题：交代发布事件（日期、官方一句话）、开源/榜单动态，引出「这期带你们完整体验 + 保姆级教程」。
- 【1:20-2:20】它到底是什么：参数信息图逐条弹出 + 官方评测数据表 + 价格对比表。
- 【2:20-4:40】场景实测（3 个）：语音唤醒+终端任务 / 百万上下文长文档 / 工具调用+全栈开发。真实操作，可标注 1.5x。
- 【4:40-6:00】复刻教程（3 步）：注册 API → 写代码（兼容 OpenAI 接口、模型名、thinking 参数）→ 让它变成贾维斯（工具调用 / 接入 Codex / 开源语音助手）。
- 【6:00-6:40】避坑点 + 结论：价格变动、版本限制、token 消耗、模型名迁移；结论句要金句化（如「人人都有贾维斯，第一次这么近」）。
- 【结尾】一键三连 + 互动问题（「如果给你一个贾维斯，你第一件事让它干什么？」）。

## 六、避坑点写法（4 个左右，每条一句话 + 一句解释）

1. 官方宣布计划近期上调价格 → 趁现在
2. 新能力目前只在 API 端 → 别被营销号带偏
3. 高级思考模式烧 token → 日常用低档
4. 旧模型名已弃用 → 记得迁移

## 七、来源标注（必须）

- 官方 API 文档、官方公告、权威媒体报道（列出名称）；画面引用处打水印/标注。
