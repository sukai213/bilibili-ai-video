## 六、附录 A：教程用代码（屏幕展示）
### curl 第一次调用
```bash
curl https://api.deepseek.com/v1/chat/completions \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "user", "content": "帮我分析这个仓库的性能瓶颈"}
    ],
    "thinking_mode": "thinking"
  }'
```
### Python 调用
```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的Key",
    base_url="https://api.deepseek.com/v1",
)

resp = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": "你是贾维斯，简洁、高效、直接办事。"},
        {"role": "user", "content": "扫描当前目录，找出所有未捕获的异常并修复。"},
    ],
    extra_body={"thinking_mode": "thinking"},
    temperature=1.0,
)
print(resp.choices[0].message.content)
```
### 工具调用（核心：让 AI 自己决定调函数）
```python
tools = [{
    "type": "function",
    "function": {
        "name": "run_terminal",
        "description": "在终端执行命令并返回结果",
        "parameters": {
            "type": "object",
            "properties": {"command": {"type": "string"}},
            "required": ["command"],
        },
    },
}]
# 把 tools 传给 create()，AI 返回 tool_calls，执行后再以 role="tool" 回传，循环即可
```
